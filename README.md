# ObraCheck — Registro de Não Conformidades

## Sobre o projeto

O ObraCheck é um projeto desenvolvido na matéria de Processos de Software, voltado ao registro e acompanhamento de não conformidades identificadas durante vistorias em obras. A proposta é centralizar as informações das ocorrências e facilitar seu acompanhamento.

## Objetivo

Permitir que o vistoriador registre uma não conformidade com descrição e evidências, enquanto o gestor acompanha as ocorrências e seus respectivos estados.

## Perfis de usuário

- **Administrador:** gerenciamento dos usuários e de seus perfis.
- **Gestor:** acompanhamento das ocorrências e análise das informações registradas.
- **Vistoriador:** registro e consulta das não conformidades encontradas durante as vistorias.

## MVP desenvolvido na UN1

Na UN1, foi elaborado um protótipo navegável utilizando o Figma Make, com telas e fluxos que representam as principais funcionalidades propostas para o sistema.

**Protótipo:** https://www.figma.com/make/8ZioTam1GHsoxkXAKynW4B/MVP-do-projeto?t=eoup4JPGo1utL0GL-1

O protótipo não deve ser confundido com uma aplicação totalmente implementada. Recursos como autenticação real, persistência de dados e integração com câmera, áudio e localização ainda precisam ser implementados e verificados, conforme o escopo de evolução do projeto.
