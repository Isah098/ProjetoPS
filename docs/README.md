# Documentação técnica — ObraCheck

Esta pasta reúne os documentos técnicos produzidos durante a UN1 para apoiar o desenvolvimento do ObraCheck.

## Documentos do projeto

- **Requisitos e User Stories:** descrição dos perfis de usuário, da User Story principal e dos critérios de aceitação.
- **Diagrama UML:** representação do fluxo de registro de não conformidades.
- **Diagrama C4 de Contexto:** visão geral do sistema e dos usuários envolvidos.
- **Diagrama C4 de Containers:** representação dos componentes considerados na arquitetura do MVP.
- **Planejamento de validação:** atividades planejadas para verificar os fluxos do sistema.

## Estado atual

Na UN1, o projeto concentrou-se na especificação dos requisitos, na modelagem e na criação de um protótipo navegável no Figma Make. A validação com usuários ainda não foi realizada, e a implementação funcional será desenvolvida nas próximas etapas.
