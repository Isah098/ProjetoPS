# Evidências do MVP — ObraCheck

Esta pasta reúne evidências visuais do MVP desenvolvido na UN1 por meio do Figma Make.

As capturas de tela documentam as interfaces e os fluxos navegáveis do protótipo, representando as funcionalidades propostas para o ObraCheck.

**Link para acessar o protótipo:**  
https://www.figma.com/make/8ZioTam1GHsoxkXAKynW4B/MVP-do-projeto?t=eoup4JPGo1utL0GL-1

**Observação:** o protótipo visual não representa, por si só, a implementação de um sistema completo com autenticação real e armazenamento persistente de dados.
